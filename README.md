# Nova IDE 🚀

**Nova IDE** is a modern, lightweight, developer-focused Android AI IDE built with Kotlin, Jetpack Compose (Material 3), and clean MVVM architecture. Designed for **Android 8.0+ (minSdk 26)** with **zero-login friction**, it brings AI-assisted coding, live localhost web preview, native Git, and an on-device Java-to-APK compiler right to your phone.

### ✨ Key Features
- **Zero-Login & BYOK AI Brain:** Works out of the box with free Pollinations.ai or your own API key (OpenAI-compatible / Groq / Cerebras / Gemini), featuring Chat, Builder, and Pipeline modes.
- **Live Web Search & 1-Tap Auto-Fix:** Built-in DuckDuckGo web search for real-time info and automatic AI bug fixing directly from WebView console or Java compiler errors.
- **Sora Code Editor & File Manager:** Syntax highlighting in a Modern Light Theme, full project CRUD, and quick **Import from GitHub** via JGit.
- **Embedded Localhost Preview:** Built-in NanoHTTPD server with responsive Mobile/Tablet/Desktop viewports and a live JS console drawer.
- **Voice & Persistent Memory:** Microsoft Edge-TTS neural voices (Hindi/English), Mic voice input, persistent SQLite chat history, and AI memory.
- **Web-to-APK & Native On-Device Compiler:** Export WebView/PWA bundles or compile native Android Java apps end-to-end on your device (`ECJ → DEX → Package → apksig v1/v2 Signing`).

# नोवा आईडीई (Nova IDE) 🚀

**Nova IDE** एक आधुनिक, हल्का और प्रोफेशनल एंड्रॉइड AI IDE है, जिसे Kotlin, Jetpack Compose (Material 3) और MVVM आर्किटेक्चर में बनाया गया है। यह **Android 8.0+** पर बिना किसी लॉगिन के तुरंत काम करता है और आपके फोन में ही AI कोडिंग, लाइव लोकलहोस्ट प्रीव्यू, Git और ऑन-डिवाइस APK कंपाइलर की सुविधा देता है।

### ✨ मुख्य विशेषताएँ
- **बिना लॉगिन के AI (Free + BYOK):** डिफ़ॉल्ट फ्री AI (Pollinations.ai) या अपनी खुद की API Key के साथ Chat, Builder और Pipeline मोड में कोडिंग करें।
- **लाइव वेब सर्च और 1-टैप Auto-Fix:** ताज़ा जानकारी के लिए लाइव सर्च और वेबसाइट या Java कोड के एरर्स को AI से एक क्लिक में फिक्स करने की सुविधा।
- **Sora कोड एडिटर और फाइल मैनेजर:** मॉडर्न लाइट थीम में सिंटैक्स हाइलाइटिंग, पूरा प्रोजेक्ट मैनेजमेंट और JGit के ज़रिए सीधा **Import from GitHub**।
- **लोकलहोस्ट लाइव प्रीव्यू:** इन-बिल्ट NanoHTTPD सर्वर, मोबाइल/टैबलेट/डेस्कटॉप व्यू और लाइव JS कंसोल।
- **वॉइस और परसिस्टेंट मेमोरी:** हिंदी/इंग्लिश के लिए Microsoft Edge-TTS आवाज़ें, माइक इनपुट, सेव्ड चैट हिस्ट्री और AI मेमोरी।
- **Web-to-APK और ऑन-डिवाइस Java कंपाइलर:** वेब प्रोजेक्ट्स को ऐप पैकेज में बदलें या सीधे फोन पर ही असली Java Android ऐप कम्पाइल और साइन (`ECJ → DEX → Package → Signed APK`) करें।
